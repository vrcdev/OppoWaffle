# OppoWaffle

Vape-style click GUI script for Operations: Siege — ESP (boxes, names, distance, health, skeletons, tracers, offscreen arrows, chams), silent aim via namecall raycast hook, camera aim, gadget/cam/door/breach ESP, gun mods (full auto, infinite ammo, no spread, no recoil, fire rate, 1.5x scope), config save/load.

## Execute

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/vrcdev/OppoWaffle/main/loader.luau"))()
```

## Controls

- **Delete** — toggle menu
- **End** — unload
- Left-click module = toggle · Right-click = expand settings
